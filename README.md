# TinyURL Clone

A modern, responsive URL-shortening website inspired by [TinyURL](https://tinyurl.com/). This project is built using React and Tailwind CSS to recreate a clean, professional interface with navigation menus and different website sections.

## 🚀 Features

- **Modern UI:** Clean and professional website design inspired by TinyURL.
- **Navigation Bar:** Easy navigation between different sections of the website.
- **Branded Links:** A dedicated section for branded links.
- **Interactive Menus:** Hover and click interactions for navigation menus.
- **Plans Section:** A section to explore available plans.
- **Resources Section:** A navigation menu for helpful resources.
- **Responsive Design:** Designed with a focus on a user-friendly browsing experience.
- **React Components:** Reusable components for easier maintenance and development.

## 🛠️ Technologies Used

- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- HTML5
- CSS3

## ⚙️ Installation and Setup

Follow these steps to run the project on your local computer.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project Folder

```bash
cd tinyurl-clone
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open the Website

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```

## 💻 Usage

1. Start the Vite development server.
2. Open the website in your browser.
3. Explore the navigation bar and website sections.
4. Interact with the available menus and plans links.
5. Explore the branded links and resources sections.
